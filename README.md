# Maria Koenig portfolio

This is a static portfolio site, ready to publish with GitHub Pages. It has no login, server, or password gate.

## Publish with GitHub Pages

1. Put this folder in a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose the branch and the repository root.
4. Save. GitHub will publish the site at its `github.io` address.

To use a custom domain, add it in **Settings → Pages → Custom domain**, then add the required DNS record with your domain provider.
